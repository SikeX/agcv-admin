# 逆变器调节闭锁功能 (Inverter Regulation Locks)

## 功能简介

本功能实现了AGC（自动发电控制）系统中的智能闭锁机制，能够根据所有逆变器的实时调节能力，自动设置上下调节闭锁状态，防止无效的调节指令。

## 业务背景

在光伏电站的AGC控制中，经常会遇到以下情况：

1. **光照充足时**：所有逆变器已达到最大出力，无法继续上调
2. **光照不足时**：所有逆变器功率接近0，无法继续下调
3. **部分故障时**：剩余在线逆变器已达到调节极限

在这些情况下，如果AGC系统继续发送调节指令，会造成：
- 无效的通信开销
- 设备频繁收到无法执行的指令
- 调度系统无法了解实际调节能力

**本功能通过智能检测所有逆变器的调节能力，在无法调节时自动设置闭锁，并将状态实时反馈给调度系统。**

## 核心功能

### 1. 上调节闭锁 (Up Regulation Lock)

**触发条件**：当所有逆变器都不能再往上调节时

**判断逻辑**：
```
对于每个逆变器：
    功率上限 = 额定功率 × (实际辐射强度 / 1000W/m²)
    
    如果 (功率上限 - 当前功率) > 0.5kW：
        该逆变器能上调
    否则：
        该逆变器不能上调

如果所有逆变器都不能上调：
    设置上调节闭锁 = 1
否则：
    解除上调节闭锁 = 0
```

### 2. 下调节闭锁 (Down Regulation Lock)

**触发条件**：当所有逆变器都不能再往下调节时

**判断逻辑**：
```
对于每个逆变器：
    如果 (当前功率 - 0kW) > 0.5kW：
        该逆变器能下调
    否则：
        该逆变器不能下调

如果所有逆变器都不能下调：
    设置下调节闭锁 = 1
否则：
    解除下调节闭锁 = 0
```

## 技术实现

### 关键参数

```go
const powerMargin = 0.5  // 功率裕度阈值（kW）
const minPower = 0.0     // 最小功率下限（kW）
```

### 检查时机

在每个AGC控制周期开始时自动检查（默认30秒一次）

### 数据流

```
逆变器实时数据 ────┐
                   ├──→ checkAndUpdateRegulationLocks()
气象站辐射数据 ────┘
                   │
                   ├──→ 计算调节能力
                   │
                   ├──→ 统计结果
                   │
                   ├──→ 更新闭锁状态
                   │
                   ├──→ DataStorage (点位405, 406)
                   │
                   └──→ DispatchStorage (发送给调度系统)
```

## 使用的数据点位

| 点位 | 名称 | 类型 | 说明 | 值定义 |
|------|------|------|------|--------|
| 405 | AGC有功上调节闭锁 | 遥信(YX) | 上调节闭锁状态 | 0=未闭锁 1=已闭锁 |
| 406 | AGC有功下调节闭锁 | 遥信(YX) | 下调节闭锁状态 | 0=未闭锁 1=已闭锁 |

## 应用效果

### 1. 防止无效调节

```
场景：光伏电站在正午，所有逆变器已达到满发状态

传统方式：
AGC系统 → 发送上调指令 → 逆变器无法执行 → 无效通信

智能闭锁：
检测到所有逆变器无法上调 → 设置上调节闭锁 
→ AGC系统检测到闭锁 → 停止发送上调指令 ✓
```

### 2. 实时调节能力反馈

```
调度系统可以实时知道：
- 当前是否可以上调功率
- 当前是否可以下调功率
- 据此调整调度策略
```

### 3. 系统稳定性提升

```
减少无效通信 → 降低系统负载
减少无效指令 → 提升响应效率
状态透明化 → 便于故障诊断
```

## 配置说明

### 可调参数

在 `agc.go` 中可以调整以下参数：

```go
// 功率裕度阈值（kW）
// 当功率距离上限或下限小于此值时，认为无法调节
const powerMargin = 0.5

// 最小功率下限（kW）
const minPower = 0.0

// 辐射数据有效性阈值（W/m²）
// 当辐射强度低于此值时，使用额定功率作为上限
if actualIrradiance < 50 {
    invPowerUpperLimit = ratedPower
}
```

## 故障处理

### 获取辐射数据失败

```go
// 如果无法获取辐射数据，使用额定功率作为上限
if actualIrradiance < 50 {
    invPowerUpperLimit = ratedPower
}
```

### 获取逆变器功率失败

```go
// 该逆变器不计入统计
totalCount--
continue
```

### 存储更新失败

```go
// 记录错误日志，但不影响AGC控制流程
global.GVA_LOG.Error("更新闭锁状态失败", zap.Error(err))
```

## 扩展性

### 支持自定义判断规则

可以扩展为：
- 基于不同逆变器品牌的差异化判断
- 考虑温度等其他因素
- 按百分比而非绝对值判断

### 支持历史统计

可以扩展为：
- 记录闭锁状态变化历史
- 统计闭锁持续时间
- 分析调节能力趋势

### 支持告警功能

可以扩展为：
- 闭锁状态长时间不变时告警
- 频繁切换闭锁状态时告警
- 与故障诊断系统集成
