# AGVC插件开发完成总结

## 项目概述

AGVC（AGC/AVC Control）插件是一个完整的光伏电站能量管理系统，实现了自动发电控制（AGC）和自动电压控制（AVC）功能。该插件严格遵循gin-vue-admin框架的开发规范，采用插件化架构设计，可独立部署和升级。

## 完成的功能模块

### 1. 数据采集与存储
- ✅ CoAP数据接收服务（端口1188，URL: /agvc/data）
- ✅ 线程安全的实时数据内存Map存储（sync.RWMutex）
- ✅ 定时自动保存到InfluxDB（每5分钟）
- ✅ 支持按PSID、EQID、EQType、DataType、Point组织数据

### 2. 设备管理
- ✅ 设备CRUD操作（创建、读取、更新、删除）

## 技术特点

### 1. 并发安全
- 使用sync.RWMutex保护内存数据
- 读多写少场景优化
- 线程安全的Map操作

### 2. 高性能
- 实时数据保存在内存，查询速度快
- 定时批量写入InfluxDB，减少IO
- 异步控制循环，不阻塞主线程
- 合理的数据库索引设计

### 3. 高可用
- 独立的控制循环，故障隔离

## API接口列表

### 设备管理（7个接口）
- POST /agvc/device/create - 创建设备
- DELETE /agvc/device/delete - 删除设备
- PUT /agvc/device/update - 更新设备
- GET /agvc/device/find - 获取设备详情
- GET /agvc/device/list - 获取设备列表
- GET /agvc/device/realtimeData - 获取设备实时数据
- GET /agvc/device/inverters - 获取逆变器列表

### AGC控制（6个接口）
- GET /agvc/agc/config - 获取AGC配置

- PUT /agvc/agc/config - 更新AGC配置
- POST /agvc/agc/start - 启动AGC控制
- POST /agvc/agc/stop - 停止AGC控制
- GET /agvc/agc/records - 获取AGC调节记录

### AVC控制（6个接口）
- GET /agvc/avc/config - 获取AVC配置

- PUT /agvc/avc/config - 更新AVC配置
- POST /agvc/avc/start - 启动AVC控制
- POST /agvc/avc/stop - 停止AVC控制
- GET /agvc/avc/records - 获取AVC调节记录

### 历史数据（1个接口）
- POST /agvc/history/query - 查询历史数据

**总计：20个HTTP API接口**

## 数据库表结构

共创建8个数据表：

1. **agvc_device** - 设备信息表
2. **agvc_point_mapping** - 测点映射表（预置40+标准测点）
3. **agvc_agc_config** - AGC配置表
4. **agvc_agc_regulation_record** - AGC调节记录表
5. **agvc_inverter_regulation** - 逆变器调节详情表
6. **agvc_avc_config** - AVC配置表
7. **agvc_avc_regulation_record** - AVC调节记录表
8. **agvc_device_reactive_regulation** - 设备无功调节详情表

## 标准测点定义

### AGC标准点（12个）
- 遥信：5个（投退信号、控制模式、开闭环状态、上下调节闭锁）
- 遥测：3个（有功上下限、执行值）
- 遥控：3个（投退、控制模式、开闭环）
- 遥调：1个（有功执行）

### AVC标准点（14个）
- 遥信：6个（投退信号、控制模式、指令状态、开闭环、上下调节闭锁）
- 遥测：4个（无功可增减容量、电压执行值、无功执行值）
- 遥控：4个（投退、控制模式、指令状态、开闭环）
- 遥调：2个（电压执行、无功执行）

### 逆变器标准点（4个）
- 遥测：3个（有功功率、无功功率、运行状态）
- 遥控：1个（开关机）
- 遥调：2个（有功功率设定、无功功率设定）

### 并网点测点（4个）
- 遥测：4个（电压、有功、无功、频率）

**总计：40+标准测点**

## 使用流程

1. **初始化**
   - 创建电站设备
   - 创建逆变器设备
   - 创建AGC/AVC配置

2. **数据采集**
   - 设备通过CoAP上报数据
   - 服务器接收并存储到内存Map
   - 每5分钟自动保存到InfluxDB

3. **启动控制**
   - 配置AGC参数并启动
   - 配置AVC参数并启动
   - 系统自动运行控制循环

4. **监控和查询**
   - 查看实时数据
   - 查询历史数据
   - 查看调节记录
