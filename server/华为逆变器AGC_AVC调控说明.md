# 华为逆变器AGC/AVC调控说明

## 概述

本文档说明华为逆变器的AGC（有功功率控制）和AVC（无功功率控制）调控流程和点位定义。

## 点位标识定义（5xx系列）

华为逆变器使用5开头的三位数作为控制点位标识：

### AGC调控相关点位

| 点标识 | 点名称 | 单位 | 寄存器地址 | 说明 |
|--------|--------|------|------------|------|
| 502 | 有功功率变化梯度 | %/s | 42017 | 有功功率变化速率限制 |
| 504 | 有功功率固定值降额(kW) | kW | 40120 | 固定功率值控制（绝对值模式） |
| 507 | 有功功率百分比降额 | 0.1% | 40125 | 百分比功率控制（百分比模式） |
| 508 | 有功功率固定值降额(W) | W | 40126 | 固定功率值控制（精细模式） |
| 510 | 有功调节模式 | - | 35300 | 0:百分比模式 1:绝对值模式 |
| 511 | 有功调节值 | - | 35301 | 有功调节设定值 |
| 512 | 有功调节指令 | - | 35303 | 执行有功调节指令 |

### AVC调控相关点位

| 点标识 | 点名称 | 单位 | 寄存器地址 | 说明 |
|--------|--------|------|------------|------|
| 501 | 无功功率变化梯度 | %/s | 42015 | 无功功率变化速率限制 |
| 505 | 无功功率补偿(PF) | PF | 40122 | 功率因数模式控制 |
| 506 | 无功功率补偿(Q/S) | Q/S | 40123 | 无功/视在功率比值模式控制 |
| 513 | 无功调节模式 | - | 35304 | 1:功率因数模式 2:Q/S模式 |
| 514 | 无功调节值 | - | 35305 | 无功调节设定值 |
| 515 | 无功调节指令 | - | 35307 | 执行无功调节指令 |

### 通用控制点位

| 点标识 | 点名称 | 单位 | 寄存器地址 | 说明 |
|--------|--------|------|------------|------|
| 503 | 调度指令维持时间 | s | 42019 | 调节指令的持续时间 |

## AGC调控流程

### 1. 百分比调节模式

百分比调节模式下，所有逆变器按相同的百分比调节功率输出。

#### 调控步骤：

```go
// 1. 设置调节模式为百分比（0）
寄存器35300 = 0

// 2. 设置百分比值（0-100%，精度0.1%）
// 例如：设置为60%，则写入值为 60 * 10 = 600
寄存器40125 = 目标百分比 * 10

// 3. 执行调节指令
寄存器35303 = 1
```

#### 使用场景：
- 需要所有逆变器统一按比例调节
- 负载均衡分配
- 快速响应调度指令

#### 代码示例：

```go
// 控制逆变器输出为额定功率的80%
err := HuaweiController.ControlAGCByPercentage(inverter, 80.0)
```

### 2. 绝对值调节模式

绝对值调节模式下，逆变器按指定的功率值(kW)输出。

#### 调控步骤：

```go
// 1. 设置调节模式为绝对值（1）
寄存器35300 = 1

// 2. 设置功率值（kW，精度0.1kW）
// 例如：设置为500kW，则写入值为 500 * 10 = 5000
寄存器40120 = 目标功率(kW) * 10

// 3. 执行调节指令
寄存器35303 = 1
```

#### 使用场景：
- 精确功率控制
- 不同容量逆变器差异化控制
- 基于实时负荷的闭环调节

#### 代码示例：

```go
// 控制逆变器输出500kW
err := HuaweiController.ControlAGCByAbsolute(inverter, 500.0)
```

## AVC调控流程

### 1. 功率因数(PF)模式

通过设置功率因数来调节无功功率输出。

#### 调控步骤：

```go
// 1. 设置调节模式为功率因数（1）
寄存器35304 = 1

// 2. 设置功率因数值（-1到1，精度0.001）
// 例如：设置PF=0.95，则写入值为 0.95 * 1000 = 950
寄存器40122 = 目标PF * 1000

// 3. 执行调节指令
寄存器35307 = 1
```

#### 使用场景：
- 功率因数调节
- 电网功率因数考核
- 标准电能质量控制

#### 代码示例：

```go
// 设置功率因数为0.95
err := HuaweiController.ControlAVCByPowerFactor(inverter, 0.95)
```

### 2. Q/S模式

通过设置无功功率与视在功率的比值来调节无功输出。

#### 调控步骤：

```go
// 1. 设置调节模式为Q/S（2）
寄存器35304 = 2

// 2. 设置Q/S比值（-1到1，精度0.001）
// 例如：设置Q/S=0.3，则写入值为 0.3 * 1000 = 300
寄存器40123 = 目标Q/S * 1000

// 3. 执行调节指令
寄存器35307 = 1
```

#### 使用场景：
- 精确无功调节
- 电压调节
- 无功补偿

#### 代码示例：

```go
// 设置Q/S比值为0.3
err := HuaweiController.ControlAVCByReactivePower(inverter, 0.3)
```

## 调节梯度设置

调节梯度用于限制功率变化的速率，防止功率突变对电网造成冲击。

### 设置方法：

```go
// 设置有功梯度为10%/s，无功梯度为5%/s
err := HuaweiController.SetControlGradient(inverter, 10.0, 5.0)
```

### 梯度计算：

```go
// 有功梯度寄存器值
寄存器42017 = 有功梯度(%/s) * 1000

// 无功梯度寄存器值
寄存器42015 = 无功梯度(%/s) * 1000
```

## 系统集成

### 初始化点位映射

系统启动时自动初始化华为逆变器的5xx点位映射到数据库：

```go
// 在系统启动时调用
err := HuaweiPointInit.InitializeHuaweiPoints()
```

### AGC控制集成

AGC服务已集成华为逆变器控制器，根据逆变器品牌自动选择控制方式：

```go
// 在executeRemoteOpenLoopControl中
if brand == cons.INVERTER_BRAND_HUAWEI {
    err := HuaweiController.ControlAGCByAbsolute(inv, targetPower)
}
```

### AVC控制集成

AVC服务已集成华为逆变器控制器，使用Q/S模式进行无功调节：

```go
// 在executeRemoteReactiveControl中
if brand == cons.INVERTER_BRAND_HUAWEI {
    targetQS := targetReactive / apparentPower
    err := HuaweiController.ControlAVCByReactivePower(dev, targetQS)
}
```

## 数据精度说明

| 数据类型 | 精度 | 示例 |
|----------|------|------|
| 有功功率(kW) | 0.1kW | 500.5kW → 5005 |
| 有功百分比 | 0.1% | 85.5% → 855 |
| 功率因数 | 0.001 | 0.95 → 950 |
| Q/S比值 | 0.001 | 0.328 → 328 |
| 变化梯度 | 0.001%/s | 10.5%/s → 10500 |

## 注意事项

1. **调节模式切换**：在切换调节模式时，应先设置模式寄存器，再设置数值寄存器
2. **梯度限制**：建议设置合理的变化梯度，避免功率突变
3. **边界检查**：系统会自动进行数值范围检查，超出范围的值会被限制
4. **品牌识别**：系统根据逆变器品牌字段自动选择控制方式
5. **错误处理**：所有控制函数都返回error，需要妥善处理错误情况
6. **日志记录**：所有控制操作都会记录详细日志，便于追踪和调试
